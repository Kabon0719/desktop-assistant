# 桌面助手 (Desktop Assistant)

一個運作於 Windows 與 macOS 桌面的透明無邊框跨平台互動角色桌面助手。

## ✨ 功能特色

1. **跨平台原生架構 (Windows & macOS)**：
   - 封裝通用平台轉接層 (`src/platform/`)，依作業系統自動派發原生系統行為：
     - **Windows**：支援登錄檔開機啟動、Win32 視窗置頂宣告、快捷工作啟動 (`.exe` / `.bat` / `.lnk`)。
     - **macOS**：支援 `launchd` plist 開機啟動、`open` 指令啟動 (`.app` / `.sh` / `.command`)、跨虛擬桌面空間 (Spaces) 浮動置頂、`~/Library/Application Support/` 使用者設定保存。
2. **背景全透明 & 無邊框**：自然融入桌面，支援滑鼠拖曳到任意位置。
3. **多組日常待命動畫循環**：
   - 支援多組循環動畫，可隨機自動切換動作。
4. **互動躍進放大 (平滑動畫)**：
   - 點擊角色時，角色會平滑放大，進入待命詢問狀態。
5. **對話選單與自訂工作捷徑**：
   - 彈出水墨金邊浮動選單。
   - **指派新工作**：內建「📜 我有新工作要給你辦」按鈕，可直接填寫工作名稱並瀏覽選擇應用程式或腳本（Windows 支援 `.exe`/`.bat`/`.lnk`，Mac 支援 `.app`/`.sh`/`.command`），自動儲存並即時加入選單！
   - **刪除工作**：在任一自訂工作按鈕上按滑鼠右鍵，即可點選「刪除此工作捷徑」。
   - **執行工作**：點擊選項時，角色會播放指定或隨機動作動畫，立即在背景啟動對應程式，並在**動作完成後自動平滑縮小回到待命模式**！
6. **🍅 內建番茄鐘 (專注計時器)**：
   - 支援倒數計時與即時懸停顯示剩餘時間；時間一到自動播放鬧鐘音效（跨平台支援 QSoundEffect 音效引擎），角色主動放大並彈出溫馨休息提醒！
7. **右鍵功能選單與應用程式設定**：
   - 隨時可在角色身上點擊滑鼠右鍵：
     - **📍 重設位置至右下角**
     - **⚙️ 編輯設定與素材...**：修改台詞、番茄鐘時長、鬧鐘音檔、匯入/匯出素材與設定，動態管理動作素材。
     - **🚀 註冊成開機啟動 / 🚫 註銷開機啟動**：依據當前系統狀態，智慧顯示對應按鈕，一鍵設定開機啟動。
     - **❌ 退出助手**
8. **📐 Ctrl / ⌘ + 滾輪快捷縮放尺寸**：
   - 在角色身上按住 **Ctrl + 滾動滾輪** (Mac 上支援 **⌘ + 滾輪**)，即可即時微調小圖待命尺寸或大圖互動尺寸，並自動記憶保存。

## 🚀 快速啟動

### 1. 安裝依賴
```bash
pip install -r requirements.txt
```

### 2. 啟動桌面助手
- **Windows / macOS 通用**：
  ```bash
  python main.py
  ```
- **macOS 快速腳本**：
  ```bash
  chmod +x run_mac.sh
  ./run_mac.sh
  ```

---

## 📦 打包發布

- **Windows 打包 (免安裝便攜版)**：
  ```bash
  python build.py
  ```
  輸出於 `dist/桌面助手/`。

- **macOS 打包 (.app Bundle)**：
  ```bash
  python build_mac.py
  ```
  輸出於 `dist/DesktopAssistant.app`。

## 🛠️ 自訂與擴充

### 1. 新增你的本機程式或捷徑
開啟 `config/actions.json`，在 `actions` 陣列中新增：
```json
{
  "id": "my_tool",
  "label": "🚀 啟動我的工具",
  "action_type": "executable",
  "target": "D:\\code\\tools\\my_tool.bat",
  "trigger_animation": "act_punch"
}
```

### 2. 調整視窗大小與切換頻率
開啟 `config/settings.json` 即可自訂小圖尺寸、大圖尺寸、FPS 與切換間隔時間。
