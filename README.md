# 桌面助手 (Desktop Assistant)

一個運作於 Windows 桌面的透明無邊框互動角色桌面助手。

## ✨ 功能特色

1. **背景全透明 & 無邊框**：自然融入 Windows 桌面，支援滑鼠拖曳到任意位置。
2. **多組日常待命動畫循環**：
   - 預設包含修煉打坐與木人樁等多組循環動畫。
   - 每隔一段時間（可在設定檔調整）隨機自動切換動作。
3. **互動躍進放大 (平滑動畫)**：
   - 點擊角色時，角色會平滑放大並靠近畫面中央，進入待命詢問狀態。
4. **待命狀態微動循環**：
   - 支援多組詢問微動姿勢輪替，點擊大圖角色本體可隨時切換動作。
5. **對話選單與本機應用程式捷徑**：
   - 彈出水墨金邊浮動選單。
   - **指派新工作**：內建「📜 我有新工作要給你辦」按鈕，可直接透過視窗填寫工作內容與瀏覽選擇電腦內的 `.exe` / `.bat` / 捷徑，自動儲存並即時加入選單！
   - **刪除工作**：在任一自訂工作按鈕上按滑鼠右鍵，即可點選「刪除此工作捷徑」。
   - **執行工作**：點擊選項時，角色會播放指定或隨機動作動畫，立即在背景啟動對應程式，並在**動作完成後自動平滑縮小回到待命模式**！
   - 點選「目前沒什麼事情要你做」，角色亦會以平滑縮小動畫退回原位繼續待命；僅點選「我有新工作要給你辦」時會繼續停留在展開詢問視窗供您設定。
6. **🍅 內建番茄鐘 (專注計時器)**：
   - 預設專注時長 20 分鐘，點擊角色呼喚對話選單即可點選「🍅 開始番茄鐘」。
   - **重複呼叫自動重設**：每次呼叫皆會清除並重設舊的計時器，重新開始倒數。
   - **狀態與提示**：倒數期間將滑鼠懸停於角色身上即可看到即時剩餘時間；時間一到會自動播放鬧鐘音效（預設為禪意罄鐘聲 `bell.wav`），角色會主動放大並彈出溫馨休息提醒！
7. **右鍵功能選單與應用程式設定**：
   - 隨時可在角色身上點擊滑鼠右鍵：
     - **📍 重設位置至右下角**
     - **⚙️ 編輯設定與素材...**：開啟專屬設定視窗，可直接修改台詞、**番茄鐘預設時長與鬧鐘音檔**、一鍵**匯入/匯出素材與設定**，以及動態新增/移除【待命修煉 (Idle)】、【詢問對話 (Asking)】與【任務執行 (Executing)】的三組動畫素材（各狀態素材至少保留 1 組）。
     - **🚀 註冊成開機啟動 / 🚫 註銷開機啟動**：依據當前 Windows 開機啟動狀態，智慧顯示對應按鈕，一鍵寫入或清除登錄檔（免 UAC 權限彈窗）。
     - **❌ 退出助手**
8. **📐 Ctrl + 滾輪快捷縮放尺寸**：
   - 在角色身上按住 **Ctrl + 滾動滑鼠滾輪**，即可即時無段放大或縮小尺寸！
   - **獨立記憶**：在待命小圖時滾動會微調「小圖待命尺寸」（60 ~ 500 px）；在展開大圖時滾動會微調「大圖互動尺寸」（100 ~ 800 px）。
   - **永久保存與匯出匯入**：調整後立即自動寫入設定檔，下次開機或啟動時完全保留最後設定的尺寸，並支援隨設定檔一鍵匯出與匯入。

## 🚀 快速啟動

### 1. 安裝依賴
```bash
pip install -r requirements.txt
```

### 2. 重新產生預留動畫圖（若需要）
```bash
python generate_placeholders.py
```

### 3. 啟動桌面助手
```bash
python main.py
```

## 🛠️ 自訂與擴充

### 1. 新增你的本機程式或捷徑
開啟 `config/actions.json`，在 `actions` 陣列中新增：
```json
{
  "id": "my_game",
  "label": "🎮 啟動原神 / Steam",
  "action_type": "executable",
  "target": "C:\\Program Files (x86)\\Steam\\steam.exe",
  "trigger_animation": "act_punch"
}
```

### 2. 調整視窗大小與切換頻率
開啟 `config/settings.json`：
- `idle_size`: `[180, 180]` (待命時大小)
- `focus_size`: `[320, 320]` (靠近詢問時大小)
- `idle_switch_interval_sec`: `20` (每 20 秒隨機切換一次待命動作)
- `fps`: `12` (動畫幀率)

### 3. 替換正式自訂素材
將自製的透明 PNG 序列圖放置於 `assets/animations/` 對應的資料夾內，檔名按順序編號（例如 `frame_00.png`, `frame_01.png`...）即可自動套用。
